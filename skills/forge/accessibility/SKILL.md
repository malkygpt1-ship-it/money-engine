# Accessibility

## Minimum checks

- Do not use colour as the only signal.
- Keep normal text contrast at least 4.5:1 where visual styling is under Forge control.
- Use descriptive headings and labels.
- Use meaningful link text.
- Add alternative text to meaningful visuals when the target format supports it.
- Keep tables simple with explicit headers.
- Avoid merged cells in data tables unless there is a compelling presentation reason and navigation remains clear.
- Give spreadsheet sheets and tables descriptive names.
- Remove empty sheets and unexplained blank structures.
- Put orientation/instructions at the start of complex sheets/documents.

## Small-screen sanity

Even when the primary artifact is desktop-oriented, instructions and purchase/delivery pages should remain understandable on a phone. Avoid requiring horizontal scanning for basic onboarding information.
